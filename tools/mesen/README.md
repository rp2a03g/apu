# Mesen 2 用: ゲームを遊びながら APU を VGM に録音する

`nes-apu-vgm-recorder.lua` は Mesen 2 の Lua スクリプト。ゲームをプレイしている最中の
サウンドレジスタ書き込み(効果音・処理落ち込み)を VGM ファイルに記録する。
できた .vgm は Sound Emulation Foundry の「ファイルを開く」でそのまま読め、
再生・ピアノロール・MML 変換まで通常の VGM(NES APU チップ)として扱われる。

NSF と違って曲を切り出す必要がなく、.nes ROM さえあればよい。先頭は録音開始地点。
「曲に合わせて効果音を鳴らす」「ジングルを割り込ませる」といったゲームを使った演奏を
そのまま残す用途。

## 使い方

1. Mesen 2 → 設定 → Script Window → **Allow access to I/O and OS functions** を ON
   (ファイル書き出しに要る。ON でないとスクリプトログにエラーが出て何も書けない)。
2. Debug → Script Window でこのファイルを開いて Run。ゲームを始める前に走らせておく
   (録音開始時点のレジスタ状態を復元するため。リセット後にスクリプトを自動再開する設定なら
   そのままでよい)。
3. 録音したい所で **F9**(録音開始)。もう一度 F9 で停止。画面左上に REC とフレーム数が出る。
4. 出力先は Mesen のスクリプト用データフォルダ
   (`<Mesen のホーム>/LuaScriptData/nes-apu-vgm-recorder/<ROM名>_<日時>.vgm`)。
   フルパスはスクリプトログに出る。

## 設定(ファイル冒頭の CFG)

| 項目 | 既定 | 意味 |
|---|---|---|
| `autoStart` | false | true ならスクリプト開始と同時に録音開始 |
| `toggleKey` | "F9" | 録音の開始/停止キー |
| `outDir` | nil | 出力フォルダ(nil ならスクリプト用データフォルダ) |
| `preciseTiming` | false | 各書き込みにフレーム内の時刻を付ける。$4011 直書き PCM を鳴らす曲向け。書き込みごとに `emu.getState()` を呼ぶので重い(headless 計測で約2割増。PCM を毎フレーム数百回書く曲では追いつかない可能性) |
| `stopAfterFrames` | 0 | >0 ならそのフレーム数で停止して `emu.stop()`(headless テスト用) |
| `flushEvery` | 60 | このフレームごとに flush しヘッダを書き直す。途中で落ちても直前までは読める |

## 記録の仕組みと制約

- 1 フレーム = VGM の 735 サンプル(1/60 秒)固定。NTSC の実レートは 60.0988Hz なので
  VGM 上の時間は 0.16% 遅いが、本ツールは 735 サンプル=1 フレームで区切るので
  フレームが 1 つもずれず、MML 変換は NSF 直接変換と同じ結果になる
  (`tools/headless/nsf2vgm.js` で NSF から同じ符号化の VGM を作り、2A03+DPCM の曲で
  変換結果が完全一致することを確認済み)。処理落ちしたフレームは書き込みの無いフレームとして残る。
- DPCM: `$4015` の bit4 を立てる書き込みの直前に、`$4012/$4013` が指すサンプル本体を
  CPU 空間から読んで VGM データブロック(0x67 type 0xC2)に入れる。同じ場所・同じ内容なら
  2 回目以降は省く。本ツールの変換は「最後に流し込まれた RAM」でサンプルを解決するので、
  同じアドレスで内容が入れ替わるバンク切替曲では最後の内容になる。
- 録音開始時のレジスタ状態: スクリプト開始後の書き込みを影レジスタに控え、録音開始時に
  フレーム 0 の頭へまとめて書く。スクリプトより前に書かれた値は分からないので、その場合は
  `$4015=$0F` だけ補う。DPCM の鳴りかけは復元しない。FDS の変調テーブル(`$4088`)も復元しない。
- 拡張音源(VRC6/VRC7/N163/MMC5/SUNSOFT 5B): VGM の規格に無いので、本ツール専用のデータブロック
  (0x67 type 0xBF、先頭 "NESX"、設計は DESIGN-CAPTURE.md §3.3)で運ぶ。標準プレイヤーは未知の型として
  読み飛ばすので 2A03+FDS だけが鳴り、本ツールは拡張音源込みで再生・変換する。どのチップかは ROM ファイルの
  iNES ヘッダのマッパー番号で決める(24/26=VRC6、85=VRC7、19=N163、5=MMC5、69=SUNSOFT 5B。
  `CFG.mapper` で強制もできる)。マッパー 26(VRC6b)はアドレス線を入れ替えて NSF の慣例(VRC6a)に正規化する。
  N163 は $4800 の読み出しでもポインタが進むので読み出しも記録する。
- GD3: track=録音日時、game=ROM 名。

## headless テスト(GUI 無し・最高速)

```
Mesen.exe --testRunner "rom.nes" "rec.lua" --timeout=60
```

`autoStart=true`, `stopAfterFrames=<n>` にしたコピーを渡すと n フレーム録音して終了する。
headless では `emu.isKeyPressed` がキー名を解決できず例外になるので、スクリプトは pcall で
包んでキー監視を自動で切る(コールバック内の例外は Mesen がログに出すだけでスクリプトは
止まらない。放っておくと毎フレーム例外で wait もヘッダ更新も飛ぶ)。
